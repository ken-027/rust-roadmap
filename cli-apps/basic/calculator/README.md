# CLI Calculator

A small interactive calculator written in Rust. It supports addition, subtraction, multiplication, division, and modulus operations on multiple numbers.

## Run

```sh
cargo run -- --operation add
```

Available operations: `add`, `subtract`, `multiply`, `divide`, and `mod`.

The app prompts for how many numbers to calculate, then prints the total. Enter `try` to run another calculation or `quit` to exit.

## Test

```sh
cargo test
```
